# Banda Nova York · site oficial

Site oficial da Banda Nova York: https://banda-nova-york.vercel.app

- Site estático em HTML, CSS e JavaScript, com GSAP 3.15 (ScrollTrigger e Flip) e Lenis 1.3, servidos localmente.
- `api/videos.js` é uma função da Vercel que lê o RSS do canal oficial no YouTube e devolve os últimos vídeos.
- Identidade visual: Rebranding V2 (Brand Book de 04/10/2026).
